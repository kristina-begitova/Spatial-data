# Пространственный анализ в R

В репозитории представлены два проекта по работе с пространственными данными в R.


## Проект 1. Построение карты городско-сельского континуума

Проект посвящен анализу пространственного распределения уровня урбанизации на основе растровых данных. Для Мехико и Стамбула выполнено объединение растровых и векторных данных, рассчитаны показатели для муниципалитетов, проведена векторизация растров и построены тематические карты городских и сельских территорий.

**Использованные методы:**

* работа с растровыми и векторными данными;
* обрезка растров по границам территории (`crop`);
* извлечение статистик из растра по полигонам (`extract`);
* классификация растровых данных;
* векторизация растра (`as.polygons`);
* объединение полигонов (`dissolve`);
* тематическое картографирование (`tmap`);
* пространственная фильтрация (`st_filter`);
* работа с административными границами.

## Проект 2. Пространственные операции с геометриями (Zion National Park)

Проект посвящен работе с векторными пространственными данными на примере территории национального парка Zion. Выполнены операции упрощения геометрии полигона, построения буферных зон вокруг точек, пространственного пересечения объектов и аффинного преобразования с поворотом полигона относительно его центра.

**Использованные методы:**

* преобразование систем координат (CRS);
* упрощение полигонов (`ms_simplify`);
* построение буферов (`st_buffer`);
* пространственное пересечение (`st_intersection`);
* вычисление центроида (`st_centroid`);
* аффинные преобразования и поворот геометрии;
* визуализация пространственных данных.
